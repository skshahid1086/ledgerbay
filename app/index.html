How will this device sync?

On a computer, run start-sync.bat (Windows) or node server.mjs in the Ledgerbay folder to host sync. Desktop app users can host from Settings.

  1. Set a passcode on the setup page (localhost only).
  2. Share the address shown (for example http://192.168.x.x:3000) and that passcode with your phone or other PC.
  3. On those devices, choose Join, enter the address and passcode, then Sync now.

Other devices need the http address from the sync host on the same Wi‑Fi.

On open, every 60 seconds, and after you save

A backup file downloads first. Merge keeps both; Replace uses only the server copy.

Run sync on a host device, then enter the address it shows. On Android, use Join with that address.
